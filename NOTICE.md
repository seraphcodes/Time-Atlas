# Third-party software and assets

TimeAtlas uses these open packages. Nothing is loaded from a third-party server at run time: fonts are bundled, and there are no analytics, cookies or trackers.

| Package | Licence |
| --- | --- |
| React, React DOM | MIT |
| three.js | MIT |
| @react-three/fiber, @react-three/drei | MIT |
| GSAP (with ScrollTrigger) | GreenSock Standard "No Charge" licence (free, including commercial use; it does not allow building a tool that lets others make visual animations without code in competition with Webflow). https://gsap.com/standard-license |
| Libre Caslon Display, Libre Caslon Text (via Fontsource) | SIL Open Font License 1.1 |
| Vite | MIT |

All 3D models, textures, sounds and the social preview image are generated by the code in this project. No AI-generated images are used. The project's own code has no open-source licence yet; it is "all rights reserved" until you choose one.
